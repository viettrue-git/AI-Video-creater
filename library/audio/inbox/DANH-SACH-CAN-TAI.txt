THƯ VIỆN ÂM THANH — DANH SÁCH CẦN TẢI (tạo 08/10/2026)

CÁCH LÀM
1. Vào pixabay.com/sound-effects (tiếng môi trường) hoặc pixabay.com/music (nhạc).
2. Gõ từ khoá gợi ý, nghe thử, chọn bài phù hợp. TRÁNH bài có nhãn "Content ID Registered".
3. Tải file về, THẢ VÀO ĐÚNG THƯ MỤC cùng tên tag bên dưới (không cần đổi tên file).
4. (Nên làm) chụp màn hình trang bài, lưu .png CÙNG TÊN với file âm thanh, cùng thư mục.
5. Báo Claude "đã tải xong" — máy tự đưa vào thư viện, đo độ to, tính âm lượng.

Mỗi thư mục 1–2 file là đủ. Tiếng môi trường nên dài ≥ 20 giây, nhạc ≥ 40 giây.
Đã có sẵn: forest, meadow-wind, music-inspiring (từ P001).
